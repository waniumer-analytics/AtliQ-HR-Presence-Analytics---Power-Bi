                                            AtliQ-HR-Presence-Analytics

                                             Domain :- HR 


                                            Project Overview

The goal of this project is to identify **employee presence patterns** within AtliQ by analyzing:

* Attendance percentages
* Work-from-home (WFH) usage
* Sick leave (SL) trends
* Month-wise workforce behavior
* Day-of-week performance
* Employee-level compliance

The dashboard enables HR managers to quickly diagnose issues, detect trends, and make informed decisions to improve overall workforce productivity and engagement.

                                                      Key Features

### ✔ **Interactive Month-wise Analysis (April–June 2022)**

* Compare attendance, WFH, and sick leave trends across months.
* Identify dips, spikes, and unusual behavioral patterns.

### ✔ **Employee-level Performance View**

* Track individual attendance %, present days, and WFH contribution.
* Pinpoint employees with attendance irregularities.

### ✔ **Day-of-Week Insight**

* Analyze which weekdays show the highest or lowest attendance.
* Track hybrid work patterns across the week.

### ✔ **Trend Charts**

* Attendance % over time
* WFH % over time
* Sick Leave % over time

### ✔ **Automated HR Recommendations**

* Each insight is paired with strategic recommendations for HR actions.

---

                                                                 Insights (Summary)

* **May has the lowest attendance (89.7%)** with the highest WFH and sick leaves.
* **Attendance dips follow a monthly pattern** around the 8th–12th.
* **Friday shows the lowest attendance and highest WFH %**, indicating preference for extended weekends.
* A few employees contribute disproportionately to low attendance (e.g., **Trystan Ortega, Zaiden Wheeler**).
* Sick Leave % gradually increases from April → June.

A detailed insights-and-recommendation breakdown is included in the project documentation.
